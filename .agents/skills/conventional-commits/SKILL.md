# Conventional Commits Skill

This skill encodes the rules for the Conventional Commits 1.0.0 specification. 

When you are asked to generate a commit message, review a commit message, or commit changes on behalf of the user, you MUST adhere to the standards defined here.

Please refer to [STANDARDS.md](./STANDARDS.md) for the detailed specification, formatting rules, and examples.

## Project rules

Beyond the specification:

- Do not add `Co-Authored-By` trailers or any other attribution footer.
